## Overview

The Chilean public health system faces ongoing challenges in managing hospital bed capacity. When occupancy exceeds ~85%, patient wait times rise, staff become overloaded, and care quality deteriorates.

This project analyzes the **REM 20 Indicators** — official monthly records from DEIS-MINSAL published on datos.gob.cl — to build a predictive model that **anticipates hospital bed occupancy** across establishments and functional areas.

**Central question:**  
> *Can we predict the hospital bed occupancy index from the operational characteristics recorded in REM 20?*

**Answer:** Yes — the Random Forest model demonstrated that the operational variables in REM 20 contain sufficient information to predict occupancy with actionable precision.

## Methodology

### Problem Type
Supervised regression — the target `INDICE_OCUPACIONAL` is a continuous percentage value.

### Data Preprocessing

- **Null values:** none detected (official mandatory administrative records).
- **Duplicates:** none detected.
- **Outlier treatment:** Winsorization at the 99th percentile for `INDICE_OCUPACIONAL` (max was 2700%), `PROMEDIO_DIAS_ESTADA` (max was 18,512 days), and `INDICE_ROTACION`.
- **Categorical encoding:**
  - `AREA_FUNCIONAL` → One-Hot Encoding (~20 categories, manageable cardinality).
  - `ESTABLECIMIENTO` → Binary Encoding (hundreds of hospitals, avoids dimensionality explosion).
- **Feature exclusion:** `DIAS_CAMAS_OCUPADAS` and `DIAS_CAMAS_DISPONIBLES` excluded from predictors to avoid data leakage (they directly compute the target).
- **Scaling:** `StandardScaler` fitted on the training set only, applied to test set afterward.

### Train / Test Split
80% training / 20% test, `random_state=42`.

### Models Compared

| Model | Notes |
|-------|-------|
| Linear Regression | Baseline — assumes linear relationships |
| Decision Tree | `max_depth=10` — captures non-linearities, prone to overfitting |
| **Random Forest** ⭐ | `n_estimators=100`, `max_depth=15` — best overall performance |

Extended comparison (10% sample) also evaluated: Ridge, Lasso, ElasticNet, KNN, LinearSVR, Extra Trees, Gradient Boosting.

### Evaluation Metrics
- **MAE** — average absolute error in percentage points.
- **RMSE** — penalizes large errors more heavily than MAE.
- **R²** — proportion of occupancy variance explained by the model.

## Results

The **Random Forest** was the best-performing model across all three metrics.

### Key findings

- Occupancy follows a clear **winter seasonality** — peaks every year in June–August.
- **2020–2021 anomaly:** sharp drop followed by recovery, consistent with COVID-19 elective surgery suspension.
- Most influential predictors: `PROMEDIO_DIAS_ESTADA`, `INDICE_ROTACION`, `NUMERO_EGRESOS`, `MES`.
- The model predicts **alert levels** (Normal < 70%, Alert 70–85%, Critical > 85%) with strong recall on the Critical class — the most operationally relevant outcome.
- Average absolute error of a few percentage points is **actionable**: a hospital manager can take preventive action (extra beds, staff reinforcement, patient transfers) when the model forecasts an approaching 85–90% occupancy.

### Alert-level confusion matrix
Evaluated by bucketing continuous predictions into three operational tiers:

| Level | Threshold |
|-------|-----------|
| Normal | < 70% |
| Alert | 70% – 85% |
| Critical | ≥ 85% |

The most costly misclassification — predicting *Normal* when the reality is *Critical* — was minimized by the Random Forest.

## Limitations

- Dataset covers **public sector only**; private hospitals are not represented.
- Some extreme outliers may reflect real events (COVID-19, local emergencies) rather than data errors — blanket winsorization may remove valid signal.
- Model predicts **monthly averages**; it does not capture daily or shift-level variation.
- Years 2020–2021 introduce atypical noise; a future improvement would be to train separate models for pandemic vs. non-pandemic periods.

## Future Work

- Incorporate external variables: ambient temperature, respiratory disease rates, national holidays.
- Explore time-series models (SARIMA, Prophet, LSTM) to better capture seasonality.
- Segment models by functional area type (ICU vs. general medicine) for higher precision.
- Evaluate gradient-boosting frameworks (XGBoost, LightGBM) — typically outperform Random Forest on large tabular datasets.
- Build an interactive dashboard where hospital managers can enter current-month indicators and receive a next-month occupancy forecast.
